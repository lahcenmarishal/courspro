# CoursPro

Plateforme digitale dédiée à la formation professionnelle et à l'apprentissage en ligne, permettant aux utilisateurs de découvrir des formations et de développer leurs compétences.

Site en ligne : https://courspro.com/

## Le problème

Trouver des formations adaptées à ses besoins professionnels peut être difficile. Les apprenants ont besoin d'une plateforme accessible pour découvrir les programmes disponibles et choisir les formations qui correspondent à leurs objectifs.

## La solution

CoursPro propose une plateforme centralisée pour présenter les formations et faciliter l'accès à l'apprentissage :

1. Découverte des formations disponibles.
2. Consultation des programmes et des détails des cours.
3. Présentation des domaines de formation.
4. Prise de contact pour obtenir des informations et s'inscrire.

## Fonctionnalités

- Design moderne et professionnel
- Présentation des formations
- Catalogue des cours
- Pages détaillées des formations
- Présentation des domaines de compétence
- Section contact
- Navigation intuitive
- Interface responsive

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS

## Installation

```bash
git clone https://github.com/lahcenmarishal/courspro.git
cd courspro
npm install
npm run dev
```
